# Conta em dia

Calendário simples de pagamentos com autenticação por e-mail e persistência no Supabase.

## Uso

1. Abra o endereço publicado no Vercel.
2. Crie sua conta ou entre com e-mail e senha.
3. Cadastre pagamentos pelo botão **Novo pagamento**.
4. Clique em um dia do calendário para marcar, reabrir ou excluir lançamentos.

A pasta contém uma aplicação HTML estática e o arquivo app.js. O projeto Vercel deve usar esta pasta como Root Directory.
